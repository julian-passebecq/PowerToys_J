# Variant: Mouse-first Project Dashboard

This branch is the closest experiment to a spreadsheet / compact clipboard panel.

Each project card shows:
- Repo, Site and optional Extra buttons that open the URL.
- A separate Copy row button.
- Inline toggles for Name / Repo / Site / Extra.
- An All toggle controlling whether the row participates in Copy all.

The copy switches are persisted when you use a row action or Copy all. Link buttons never copy text.

A separate Manage Project Rows command keeps add/edit/delete operations out of the compact dashboard.

Use this branch if visible buttons matter more than pure keyboard density.
