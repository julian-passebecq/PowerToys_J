# Variant: Compact Project Grid

This experiment optimizes for many parallel projects.

- Projects render as `SmallGridLayout` tiles instead of long rows.
- Selecting a tile opens its preferred deployed site.
- The always-visible details pane contains clickable GitHub/Site/Extra links.
- Copy row / copy individual URL actions remain visible in details.
- Add Project and Copy All are tiles in the same grid.
- The rest of the full J Utility Palette remains available.

This is the best candidate if the number of active repos grows and a vertical list becomes too long.
